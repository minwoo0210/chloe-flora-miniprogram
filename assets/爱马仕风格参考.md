# 爱马仕体验店小程序 — 设计风格参考规范

> 来源：用户提供的爱马仕体验店小程序录屏分析。花艺商城小程序需严格参考以下设计规范。

## 1. 配色方案
- **主背景**：大面积低饱和度米白色 / 米灰色（避免高饱和亮色干扰商品展示）
- **强调色**：爱马仕标志性橙色（约 #E8830C），仅在底部 Tab 选中态、核心操作按钮上低调使用
- **文字**：深灰色 + 浅灰色层级区分（不使用纯黑），通过深浅差异区分标题/价格/辅助说明

## 2. 页面布局
- **首页**：全屏滚动流式布局；顶部固定品牌 logo；首屏品牌主题视觉海报；向下为各品类主题宣传区（场景化宣传大图 + 文案），下方衔接对应品类商品展示模块
- **商品展示**：2 列网格卡片式，卡片含商品图、名称、价格，信息排布均衡
- **顶部导航**：品类横向滚动导航栏（可左右滑动切换品类）
- **底部 Tab**：固定 5 个导航入口，选中态橙色图标+橙色文字，未选中灰色

## 3. 字体与排版
- 无衬线简洁现代字体，笔画粗细均匀、克制优雅
- 三级排版体系：大字号=品类主题宣传标题，中字号=商品名称与价格，小字号=辅助说明
- 文字左对齐，留白充足，视觉节奏舒缓

## 4. 视觉细节
- **卡片**：无边框设计，依托背景色自然区分，轻盈通透
- **圆角**：按钮和控件使用极小圆角，避免过度圆润
- **间距**：元素间距宽松、留白充足，不密集排布
- **图片**：高品质时尚大片风格，光影细腻、画面质感统一

## 5. 整体调性
奢华简约：大量留白弱化商业感，无复杂装饰元素，视觉重心聚焦品牌内容与商品展示，克制优雅。

## 6. 页面结构参考
1. **首页**：品牌 logo → 品牌主题全屏宣传区 → 各品类主题滚动区（宣传文案+配图）→ 商品展示网格
2. **品类商品页**：顶部 logo + 品类导航 → 品类主题宣传大图 → 子分类 → 2 列网格商品
3. **商品详情页**：返回 + logo → 商品轮播图 → 名称/售价 → 颜色选择 → 参数说明 → 服务选项 → 关联推荐 → 底部固定「加入购物袋」+「立即购买」
